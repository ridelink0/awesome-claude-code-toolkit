# Plugin audit fixes — 7 September 2026

All 120 plugin command paths and marketplace sources now use valid ./ paths. The root author uses an object. Plugin versions are 1.0.1.

[Cross-repository audit, reproductions and verification results](https://github.com/ridelink0/cinematic-web-design/tree/master/docs/audit-2026-09-07)

See the verification report for tested scope and limitations. Native desktop interaction, external service authentication and generated website visual quality are not covered by static validation.

The full validator also exposed legacy hook-array schema. Hooks are now grouped by event with command entries and script paths rooted at the installed plugin.
